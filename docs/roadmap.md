# Roadmap

正本は GitHub Issues。本書は優先順位と選定理由の要約。新しい発見があれば組み替える（初期計画を守ること自体は目的ではない）。

## 優先順位の考え方
高インパクト×低コストを優先。高インパクト×高コストは小さな技術検証から。低インパクト×高コストは後回し。

## Phase 1-2: 基盤とMVP（着手済み 2026-11-05）
- レシピ駆動の共通ビューア（場所/カメラ/素材/時刻/演出をJSONレシピで再現可能に）
- コンタクトシート（同一条件の複数案を比較、各案→ビューア直リンク）
- ギャラリー（採用作品のみ）

## Phase 3: 最初の3企画
1. **EXP-003 MATERIAL TOKYO（最初のPDCA）** — 理由: AWAKENINGで実証済みのFeatureEvaluatorスタイリングをそのまま再利用でき、同一構図6素材の比較が最も低コストで「レシピ×バッチ比較」基盤の検証になる。氷/ガラス/黄金/クローム/陶器/発光クリスタル。
2. **EXP-002 CITY GROWTH** — 出現順（中心→外側 / 低→高 / ランダム / 巨大ビル最後）を `show` フラグ+重心・高さ属性で実装可能と見込む。動きが核なので早期にアニメーション試作。
3. **EXP-001 CITY LIFT** — Navara単体ではタイルの幾何切断・切断面生成ができないため、まず LIFT-LITE（地形・写真を消し暗背景に建物群だけを浮遊ジオラマとして孤立させ、緩やかな周回+浮遊感）で構図の魅力を検証する。真の切断面はBlender経路（PLATEAU CityGML→メッシュ化→切断）で別途技術検証する。
