# Vision

## 最終目標
Navara × PLATEAU × Blender × Creative Coding を活用し、実在する3D都市モデルから、思わず見返したくなる・共有したくなるビジュアル作品・映像・インタラクティブコンテンツを継続的に生み出す仕組みを構築する。

出発点はXで注目される3D都市作品: 街のジオラマ切り出し、建物が地面から生える成長、素材変換、空撮のような飛行、分解・再構築、ありえない構図や世界観。

## 価値
Navaraで何ができるかの調査が目的ではない。NavaraとPLATEAUを活用したからこそ、従来より効率よく面白い都市作品を作れることが価値。

## 成功の姿
- 新しい表現が継続的に見つかり、試作され、比較され、学びが蓄積される
- GitHub Pagesギャラリーに魅力的な作品が増える
- ユーザーが細かく指示しなくても、許可済みの作業が進んでいる

## 媒体の原則（2026-11-06、ユーザー決定で改訂）
**Navara作品は動的コンテンツとして見せる。静止画にしない。**
- 根拠: 静止画ではNavaraはBlenderと同じ土俵で競うことになり、LODの粗さや昼焼き付けの地面など弱点だけが露出する。Navaraの強みはリアルタイム性 — 成長・浮上・時間変化・カメラの振り付けを、レンダリングなしに再生し続けられること。
- 作品の完成形: GitHub Pages 上のライブピース（URLを開けば自動再生で演技が始まる）。静止画はポスター／サムネイルに降格する。
- Blenderラインは別系統として正直に分ける: PLATEAU × Blender のレンダリング済み短編映画（EXP-013/014等）。これはNavara作品ではない。
- SNS用ループ動画が必要な場合は Blender ラインで作る（NavaraのWebGLキャプチャは当環境では不可、という既知制約のため）。
