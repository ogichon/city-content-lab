# Creative Playbook — 有効だった表現の蓄積

実験から抽出した成功パターンだけを書く。失敗は lessons-learned.md へ。

## 技術検証repoから継承した確定パターン
- 夜・夕景の地面: 航空写真ティント+環境光+露出で持ち上げる（夜: 0x51628c / 0.6 / 1.7）。これ未満だと地面が黒に潰れる（AWAKENING Gold初期版でユーザー指摘により確定）。
- 高さグラデーション発光: 低層=琥珀、高層=淡い金のように高さで色を変えると建物形状が読める（AWAKENING都庁Gold、ユーザーのスクリーンショットで形状可読性を確認）。
- 体積雲+ライトシャフト+選択的ブルームは Navara の最も差別化できる見た目（takram系フォトリアル）。
- カメラは作品の一部: 注視点=ランドマーク自体、distance 520-560、pitch -46〜-48 が東京駅/都庁の実証済み初期値。

## ユーザーフィードバック記録
- 2026-11-05（技術検証repo）: AWAKENING Gold で「ベースマップが表示されてなくない？」→ 地面と空が潰れる表現は減点。建物の色が良くても地面が読めなければ作品として弱い。

## 未検証（仮説プール）
- 素材変換は「形状が読める素材」（黄金・陶器）ほど強く、透明系（ガラス・氷）は形状が溶けて弱い可能性。
- ジオラマ感は俯瞰+暗背景+被写界深度の組み合わせで強まる可能性。

## Blenderオフライン経路（2026-11-05 実証）
- plateau-tokyo-station の資産（Blender 4.2.9 ローカル導入、東京駅シーン .blend、Cycles CPU）がそのまま使える。新規導入不要だった。
- 同一カメラ素材差し替えは scripts/blender/render_materials.py で自動化済み。960×540/32サンプルで1枚約110秒 → 4素材の対照実験が約8分で回る。
- 素材の学び: 金属（金）は暖色太陽光で最も映える。不透明な淡色誘電体（氷）は影の対比が弱く平たくなる — 氷・ガラス系は透過表現が必須。平面金属は低サンプルでデノイズ粒が出る（128サンプル目安）。
- 制作分担の原則: 「素材・構図の当たり探索はBlender」「リアルタイム性・属性連動・量産はNavara」。どちらか一方に固執しない。
- 改善ラウンドの学び（2026-11-05 PDCA #3）: 金は低太陽+低露出で濃く劇的になる。透過は全建物一様だと霧化して失敗する（中実LOD2では厚み表現ができない）。平面金属は128サンプルで粒が消える。
- **ヒーロー素材の原則（仮説H4）**: 素材は街全体に一様に塗るより、「地は可読性の高い素材、ランドマークだけ別素材」が意外性と実在感を両立できる可能性が高い。次ラウンドで検証。
- **ヒーロー素材は支持された（2026-11-05 PDCA #4）**: 地を可読性の高い素材（磁器）にし、ランドマークだけ別素材（金）にすると、全一様適用より第一印象・焦点・実在感のすべてが上がった。「素材の意外性は全面ではなく一点の裏切りで作る」を原則化する。領域指定レンダは scripts/blender/render_hero.py（デバッグ色での較正手順含む）。
- シリーズ化（2026-11-05 EXP-005）: ヒーロー素材は都庁でも成立し、「白い都市、金のランドマーク」はシリーズの型になった。単一メッシュシーンでは面重心で分ける render_hero_split.py を使う。ランドマーク同定は「高頂点の分布→2色デバッグレンダ」の較正手順が速い（約20秒/回）。
