# EXP-013 — 万博モーション本制作（テスト群の先）

## 背景
ユーザー評価（2026-11-06）: 「がんばって、まだ物足りない」。これまでの動画は全て 640×360/12サンプルのテスト画質で、構図と動きの確認止まり。作品としての完成度が足りない、という指摘として受け取る。

## 「足りる」の定義（本制作の仕様）
- 解像度・サンプル: 1280×720 / 32サンプル（テストの4倍画素・2.7倍サンプル）
- 画調: ドラマチック（低太陽 66,4,150°・環境光0.55・AgX High Contrast・露出-0.15）
- 世界: 周辺都市（EXP-012、変換済み）＋修正済みDEM地形＋カメラ専用スカイ
- 動き: 3幕（設備の寄り→上昇→全景）。教訓: 寄り→引き版は中盤で高所に着きすぎた — 上昇は後半に寄せ、寄りの滞留を長く取る
- 長さ: 144フレーム（6秒・24fps）。推定 ~3分/フレーム → 約7時間のバックグラウンド描画

## 追加の探索（安い実験）
- 真上パターン: 設備の密集地を真上から見るグラフィックな画（竹芝の真上を選んだユーザーの嗜好と接続）。静止画1枚で判定する。

## ACT
- 3幕テスト（EXP-010系）の完走後に動きを確定し、本制作を長時間ジョブとして回す。
- 完走までは逐次実行を厳守（並列レンダ禁止の教訓）。

## 結果（2026-11-06 完走）
144フレーム全完走（ランタイム再起動で3回寸断→ --frame-start で都度再開、欠けなし）。成果物: output/blender/exp013-motion-production.mp4 (1280×720, 6.1MB)。格子の寄りはテスト版と別物の解像感、全景は周辺都市＋地形で周縁が埋まった。
