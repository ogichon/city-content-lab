# EXP-018 — プローブ v3: 診断ファースト化

## 証跡
EXP-017（PR #39）配信後も、ユーザーのスクショ（image-66、&v=17 の新URL）で
プローブは "probe …" のまま。数値もエラー表示も出ない。v1/v2 に共通する沈黙は、
サンプリング以前の段階（ハンドラ到達・開始タイミング・描画との同期）の
どこかで止まっていることを示すが、静止画だけでは分離できない。

## DO（変更はプローブのみ・単一変数）
- 1秒間隔のハートビートが要素を無条件に書き換える（経過秒数を表示）
  → 新コードが動いているか自体がスクショで分かる。
- postRender は素のカウンタとして数える（f=フレーム数）
  → イベントが届いているか／サンプリングだけが死んでいるかを分離できる。
- サンプラは値かエラー名を probeState.text に残し、ハートビートが表示する。

## 読み方（次回スクショ1枚で確定）
- 秒数が増えない → そのタブは旧ビルド or JS停止。
- 秒数は増えるが f0 → postRender が view.on に届いていない（イベント経路の問題）。
- f は増えるが text が init のまま → 開始フラグ／間引き条件の問題。
- err ○○ → 読み出し（汚染・サイズ等）の問題で、○○がそのまま原因名。
- 数値が出る → 解決。以後は輝度の判定に使える。
