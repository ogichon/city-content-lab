# EXP-001 CITY LIFT — 東京を切り取って持ち上げる

## PLAN
- 仮説: 街をジオラマとして切り出し暗い背景に浮かべると、通常の地図表示にはない「物体としての街」の魅力が出る。
- 実現性検証（Muse事前評価）: Navara/3D Tiles はストリーミング描画であり、タイル幾何の任意形状クリッピング・切断面生成・地形ごとの持ち上げは標準機能にない。したがって2段階にする。
  - LIFT-LITE（今回）: 地形・航空写真を外し、建物群だけを暗い虚空に孤立させ、緩やかな周回+距離の呼吸で浮遊感を作る。構図の魅力だけを安く検証する。
  - 真のLIFT（保留）: PLATEAU CityGML を Blender でメッシュ化し、矩形/円形で切断して切断面（地層表現）を作る経路。コスト高のため、LITEの構図評価が良ければ着手する。
- 成功条件: LITEで「浮いている模型」に見える構図が成立するか（ユーザー目視）。成立しなければ切断面なしでは弱いという知見が得られる。

## DO
- LIFT-LITE をビューアに実装（Codex A、独立レビューで「地形切断なしの明示」「地形/写真レイヤーを積まない」ことを確認）: 東京駅・都庁の2レシピ。暗背景+夜グレーディング+緩やかな周回と距離の呼吸。

## CHECK
- 技術評価: 基盤テスト・ビルド PASS。
- クリエイティブ評価: **未確認**。最大の懸念は「地形がないと浮遊ではなく、ただ暗い場所に建物があるだけ」に見える可能性。その場合は LITE は撤退し、Blender 切断経路の優先度を上げる。

## ACT
- 判定: **保留（目視待ち）**。再開条件は LITE の目視評価。良ければ DOF（tilt-shift）追加でジオラマ感を強化、悪ければ Blender 経路の技術検証 Issue を切る。
