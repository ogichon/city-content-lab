# EXP-022 — 沈む街（フラッグシップ転換）

## 決定（2026-11-09、Muse=クリエイティブディレクター）
- フラッグシップを BREATHING CITY（EXP-021、出現の潮汐は不成立で終了）から本作に切替える。Navara側プロトタイプ UNDERWATER の発想を CCL で作品として作り直す（色設計は継承しない）。
- ルールは1つ: **水位だけが上がる**。何が沈み何が残るかは実標高と実高さが決める。
- 色の塗り分け（浸水深カラーマップ）は禁止。建物は単一素材（磁器系）、水面下は水を通して沈み、水面が画の主役。
- 舞台: 隅田川沿いの低地と丸の内の境目（中央・千代田タイル範囲）。水位上昇で川沿い低層が沈み、高層群が島として残る。

## 技術スパイク結果（2026-11-09、SDKソース＋プロト実装の読解）
- 水面: `view.addMesh` の plane（geodetic height=楕円体高、transparent/opacity指定可）。水位変更は `plane.update({geodetic:{height}})` の部分更新で安価 — プロト実証済み。
- 建物ごとの素材制御: FeatureEvaluator で color/emissive/opacity を属性駆動できる（CCL既存機構と同系）。
- 未解決: 建物ごとの地盤標高はタイル属性に無い。低地では地盤が近似的に一様なため、試作では「水位 vs 建物高さ」で沈没順を近似し、限界として明記する。
- 結論: 既存機構で構成可能。残る問いは水面の見えの質のみ — 核の瞬間の試作で判定する。

## 試作（核の瞬間）
- ステージ作品として実装: 48秒ループで水位 0→12m 上昇→静止→下降。夕景、地面は写真そのまま、建物は磁器単一素材、水面は半透明でわずかに反射を帯びる。
- 判定: 再生で「水面が街を呑む瞬間」が説明なしに掴めるか。掴めなければ方向ごと記録して捨てる。

## CHECK/ACT（2026-11-13、ユーザー提供 image-111〜113、fix1版）
- 31s（w12.0・最大水位）: black 100%、完全な黒。水面も街も存在しない。
- 51s（w0.6）: 街は見える（月島・川・橋）が、建物は全棟が無照明の濃紺シルエット。磁器は一度も現れなかった。水位0.6で沈没対象がほぼ無いはずなのに全棟が暗い＝水の素材分岐ではなく、夕景×カスタムスタイル経路そのものがシルエット化している。EXP-021 の高位相シルエットと同一の欠陥。
- 61s（w3.5）: 再び black 100%。黒の区間が繰り返し訪れる。
- 判定: **核の瞬間は不成立**。理由は3つ — (1) 水が水として一度も見えない (2) 磁器が成立せず全棟シルエット (3) 黒の区間が反復する。概念（水位だけが上がる）ではなく、このビューアの夕景照明経路が2作品連続で同じ壁に当たった。
- 方針判断はオーナーへ: (A) ライブWeb路線を維持し照明経路の原因調査からやり直す / (B) フラッグシップを Blender 映画レーンへ移す（本ラボでユーザーの承認を得た画は全て Blender 産）。Muse の推奨は B。
