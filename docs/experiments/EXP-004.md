# EXP-004 CAMERA LANGUAGE — カメラだけで都市の印象を変える

## PLAN
- 仮説: 同じ実在都市・素材・照明でも、距離と俯角を変えることで都市の迫力、形状の読みやすさ、模型らしさが変わる。
- 比較条件: 東京駅、黄金素材、夕景、seed 1、コードバージョン 0.1.0、`group: controlled`。注視点（lng 139.7671 / lat 35.6812）、heading 55、roll 0 を固定し、距離とpitchだけを変える。

| ID | 案 | distance | pitch |
| --- | --- | --- | --- |
| exp004-standard | 標準（上書きなし） | 520 | -48 |
| exp004-low-angle | ローアングル | 380 | -18 |
| exp004-top-down | 真俯瞰 | 700 | -85 |
| exp004-diorama | ジオラマ俯瞰 | 900 | -55 |

- 真俯瞰案は指定値 -85 度のほぼ真上視点。レシピの `cameraOverride` を基準カメラへマージし再現する。
- 成功条件（技術）: 4レシピが同じ素材・場所・時刻を維持し、3案の上書きと標準案の既定値が初期表示・リセット・復帰で保持される。テストとビルドが通る。
- 成功条件（クリエイティブ）: ユーザーChromeで同条件の画面を横並び比較し、標準より魅力的な構図を少なくとも1案見つける。100点ルーブリック（第一印象30 / 独自性20 / 都市らしさ20 / 構図15 / 活用の意味10 / 品質5）を用いる。
