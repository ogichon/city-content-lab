# EXP-005 — HERO LANDMARK（ヒーロー素材の横展開）

仮説: 「地は磁器、ランドマークだけ金」のヒーロー素材（EXP-003 PDCA #4 で支持）は、場所を変えても成立するか。

## 都庁（新宿）での検証 2026-11-05
- シーン: plateau-tokyo-station の shinjuku_tocho_scene.blend。東京駅シーンと違い街全体が単一メッシュ（115,224面）のため、面の重心で素材を分ける render_hero_split.py を新設。
- 都庁舎の特定: 高さ225m超の頂点分布から候補を2クラスタに絞り、赤/青のデバッグレンダで同定。較正済み領域（world座標）: x[-340,-120] y[120,280]、2,730面。
- 構図: シーン既定カメラでは双塔の頂部が切れたため、視線方向へ150mプルバックして全景化（--pullback オプション追加）。
- 成果物: output/blender/exp005-tocho-hero-gold.png（近い画角）/ exp005-tocho-hero-gold-wide.png（採用候補）

### 評価（Muse）
- 技術: 素材分離は正確（都庁舎のみ金、他は磁器）。描画不具合なし。前景の広場に小さな金の断片2点（領域内の小物）がある。
- クリエイティブ: **ヒーロー素材は都庁でも成立**。双塔のノッチ形状が金で際立ち、白い新宿の高層群との対比がシリーズ感を作る。東京駅版の方が文脈の豊かさで上だが、シリーズ2作目として十分な水準。**ギャラリー採用候補 #2**（最終判断はユーザー）。
