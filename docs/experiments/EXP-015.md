# EXP-015 — ステージモード（Navara作品の動的化）

## PLAN
仮説: Navara作品を「自動再生される演技（カメラ振り付け＋成長/浮上/時間変化）」としてWebで演じれば、静止画では露出する弱点（LODの粗さ・昼焼き付け）が視差と動きで相対化され、Navaraならではの価値（リアルタイム・無限再生・URLで共有）が出る。ユーザー決定（2026-11-06）: 「Navaraを活かすのであれば静止画にしないほうがいい。動的コンテンツとしてみせるべき」→ 組み直しを承認。
成功条件: 既存レシピ3本（lift/growth/material）が stage URL で自動再生の演技として開ける。既存ビューアの挙動は不変。テスト全通過。

## DO
- Recipe に performance（shots列＋easing、任意で時間ドリフト、loop）を追加。
- ビューアに stage モード（URLパラメータで起動、UIを隠し __idle 後に再生、__stage で計装）。
- ギャラリーのカードから動的ピースへのリンクを追加。
- 実装は Codex（worktree）、レビューと統合は Muse。
