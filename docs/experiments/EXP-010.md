# EXP-010 — 動画で確認する（モーション検証の型）

## 背景
ユーザー提案（2026-11-06）: 静止画で確認できない表現を動画で確認できないか。LOD1の場所（スカイツリー周辺など）は静止画では「塊」にしか見えず、従来ルールでも動画素材扱いだった。

## DO
- 万博ヒーローの構図を起点に、海側をゆっくり寄りながら横移動するドリーを実装（build_expo_scene.py に `--anim --frames N --cam2/--target2` を追加、PNG連番→ffmpegでMP4化）。
- テスト条件: 96フレーム（4秒・24fps）、640×360、12サンプル。所要約28分（逐次実行）。

## CHECK
- 技術: 全フレーム描画成功、MP4化（H.264、0.7MB）。開始→中間→終了フレームで視差の連続性を確認 — 格子の前後関係、遊歩道の格子影、奥のパビリオンが層になって動く。
- クリエイティブ: 静止画では平らに見えた格子が、寄りの最終フレームでは「奥行きのある構造」として読める。動画確認は有効 — 特に格子・重なり・浮遊（LIFT）のような視差依存の表現では、静止画判定より正確に作品性を測れる。

## ACT
- 採用: モーション確認を正式な評価経路として追加する。視差依存の表現（格子、LIFT、LOD1の場所）は、静止画ゲートに加えて短尺ドリーで確認する。
- コスト知見: 640×360/12サンプルで約17秒/フレーム。本番画質の動画（1920×1080/128）は現行CPUでは非現実的なので、動画作品は「低解像度で確認→必要なら解像度を絞って本番」という運用にする。
- 次: スカイツリー LIFT のモーション確認（静止画で却下された題材の再評価）。
