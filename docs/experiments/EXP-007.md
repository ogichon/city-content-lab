# EXP-007 — 大阪・関西万博（大屋根リング）

## 目的
ユーザーの題材指定（2026-11-05）。品質ゲート（静止画グレード）を満たしうる高精度データでの初実験。大屋根リングは建築BIM由来 — LOD1/2とは別格の形状精度が見込める。

## データ
- PLATEAU「2025年大阪・関西万博会場 3D都市モデル」(G空間: plateau-27999-osaka-shi-2025, v4)
- CityGML ZIP 357MB（data/expo2025/citygml.zip、git管理外）
- **ライセンス: 独自利用規約・商用利用禁止**。本Labの研究/作品用途に限定し、収益化の対象にしない。
- 併せて GeoTIFF（オルソ画像）も同データセットにあり、ベースマップとして使える可能性がある。

## 進め方
1. CityGML → OBJ 変換（最高LOD優先、座標は会場中心で再センタリングしたメートル系）
2. Blender シーン構築（リング同定: bbox/形状から）
3. 品質ゲート前提の静止画: ヒーロー素材（会場=磁器、リング=金）を最終画質で

## 検証（2026-11-06、ユーザーの「なんかおかしくない？」を受けて）
- 同梱オルソ画像（GeoTIFF 6タイル）をモデルのローカル座標へステッチ（scripts/make_expo_ortho.py、.tfw は度単位 → EPSG:6674 へ投影し変換器と同じアンカーで配置）。
- 真上（正射）でモデルを写真に重ねて検証: **金のリングは写真のリングと完全に一致、パビリオン群も写真の footprint 上に乗る** — 配置・向き・縮尺は正しい（output/blender/exp007-verify-nadir2.png）。
- 黒い三日月領域の正体: ウォータープラザ（水盤）の basin シェル（frn_5ce668fc）。単体分離レンダリング＋発光マテリアル試験で切り分け — 配置は正しく、面の向きでもマテリアル割り当てでもなく、開いたシェルの内側に Cycles の光が届かず純黒になる現象。実物は水面なので、シェルを隠して写真の水面を見せるのが正解とした。
- 教訓: 「おかしい」の切り分けは ①実写との重ね合わせ（配置）②単体分離（オブジェクト特定）③発光試験（可視性 vs 照明）の順で機械的にやる。推測でマテリアルや法線をいじらない。
- 解決（同日）: basin シェルを隠し（写真の水面が透ける）、マテリアルに同色の弱い発光リフト（16%）を追加 — 未照光シェルが純黒に落ちる現象は全オブジェクトで解消。検証画像は exp007-verify-nadir3.png / exp007-verify-oblique3.png。最初の仮説（法線反転）は分離実験で否定された — 反転しても黒いままだった。
