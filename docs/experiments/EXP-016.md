# EXP-016 — ステージの暗さ: 構造的グレードと輝度プローブ

## 背景（証跡）
- ユーザー実見: ステージ作品が暗く、画角を引くと真っ暗になる（2026-11-06〜07）。
- EXP-015修正（画角を検証済み範囲へ＋露出×1.25）では直らなかった。
- 姉妹プロジェクト AWAKENING のスクリーンショット（ユーザー提供 image-59/60）が決定的証跡:
  地面の写真が潰れて真っ黒、建物は粒子ノイズ混じりの暗い金茶。ベースマップ確認ONでも地面が黒い
  → 色ではなく照明で潰れている。
- 姉妹側のSDK調査で確定した機構: (1) 16:30の太陽高度は約+1.5°で、水平面への直射は約3%
  → 照明付き地形では地面が死ぬ。(2) photorealシーンの大気（aerial perspective）の
  transmittance が距離で光を消光する。(3) 体積雲の haze が距離減光に重なる。

## DO（ステージ限定・静止画レシピは不変）
- 地形レイヤーを `lit: false` で更新（地面の明るさはレシピの色調のみで決まる）
- `scene.aerialPerspective` の transmittance を false
- 雲エフェクトの `hazeDensityScale` を 0
- 輝度プローブ: postRender（キャプチャと同じ読み出し点）で 48×27 に縮小サンプリングし、
  平均輝度・下半分（地面）平均・黒つぶれ率を `__stage.probe` と画面右上表示に供給。
  「暗いか」を印象でなく数値で検証可能にするための計装。

## CHECK / ACT
目視と数値はユーザーのブラウザで確定する。プローブ数値の読み:
shot 3（最遠）で ground が 0.1 を大きく下回る／black が過半なら未解決として次手を打つ。
成立すれば、同じ構造を静止画レシピへ広げるかは別途判断する。
