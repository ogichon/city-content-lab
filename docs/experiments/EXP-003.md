# EXP-003 MATERIAL TOKYO — 東京を異なる素材で作り直す

## PLAN
- 仮説: 実在の東京駅周辺の形状を保ったまま素材だけを変えると、通常の3D都市表示より強い視覚的インパクトが得られる。特に「形状が読める素材」（陶器・黄金）ほど強く、透明系（ガラス・氷）は形状が溶けて弱い可能性がある。
- 狙う驚き: 見慣れた街が一瞬で別素材の模型に変わる違和感。
- 比較方法: Controlled は東京駅・同一カメラ（distance 520 / heading 55 / pitch -48）・夕景固定で6素材。Best Look は同じ場所・カメラで素材ごとの時刻を選び、別群として評価する。
- 成功条件（技術）: 12レシピすべてが再現可能に切替表示でき、テストとビルドが通る。
- 成功条件（クリエイティブ）: ユーザーのChrome目視で「明らかに違う1枚」が少なくとも1案あること。AI側では判定しない。
- 技術的誠実さ: NavaraのFeatureEvaluatorで可能なのは color/metalness/roughness/opacity/emissive の近似まで。真の屈折・環境反射は未実装であり、必要ならBlender経路へ送る。

## 次への5問
1. 何が分かったか: Navaraの素材表現は「色+金属度+粗さ+透明度+発光」の近似が限界であり、ブルーム接続（effectIds）と透明設定（transparent）が無いと意図した素材にならないことが、レビューで実装前に近い段階で検出できた。
2. 支持された仮説: レシピ+FeatureEvaluatorで同一構図の素材比較が再現可能に回る（基盤仮説は技術的に支持）。
3. 否定された仮説: 「opacityを返せば透ける」「emissiveを返せば光る」は誤り。Navaraではレイヤー/エフェクト側の接続が別途必要。
4. 次に変えること: ユーザー目視の勝ち素材を軸に、カメラ（低空）と場所（都庁）へ横展開する。負け素材は理由を記録して撤退判断する。
5. 再利用できる知見: effectIds/transparent の作法は全ての発光・透明系実験（X-RAY、UNDERWATER横展開等）に効く。lessons-learned.md へ転記済み。

## Controlled / Best Look 分離（ユーザー指示 2026-11-05）
- 理由: 素材そのものの比較と、素材が映える照明の探索を分ける。従来の昼クローム・夜クリスタルを含む混在条件では、素材差と時刻差を切り分けられなかった。
- Controlled: 既存の `exp003-*` 6 ID を維持し `group: controlled`、すべて東京駅・夕景・共通カメラ・seed 1。クロームとクリスタルも夕景へ統一。
- Best Look: `exp003-best-*` 6件を追加し `group: best`。陶器/黄金は夕、クローム/氷/ガラスは昼、発光クリスタルは夜。場所・カメラ・seed は Controlled と共通。
- DO: TS と JSON に両群を記録。比較HTMLの変更はこの作業の対象外。
- CHECK（技術）: レシピ17項目とビューア契約テストは PASS。`npx vite build` も PASS（Vite 8.3.5、chunk サイズ警告あり）。Draco/font worker wasm と cloud/noise/water のコピーを確認。依存はオフラインキャッシュ不足のため既存ローカルチェックアウトの node_modules をコピーして使用。これらは描画完了を証明しない。
- CHECK（クリエイティブ）: **未確認**。Best Look は最適との確定評価ではなく候補。ユーザーChromeで各群を別々に比較する。
- ACT: 条件統一を採用。素材の優劣は Controlled、作品候補の魅力は Best Look で評価し、ユーザーの目視結果を追記する。

## PDCA #2 — Blender オフライン対照実験（2026-11-05、Muse評価済み）
Navara版の目視が撮影経路に阻まれたため、同一問い（素材だけを変えたら何が起きるか）をブラウザ非依存のBlender経路で先に検証した。

### 条件（Controlled相当）
- データ: PLATEAU 東京23区 LOD2（53394611 東京駅・丸の内 1km²、plateau-tokyo-station の実証済みシーン .blend を再利用）
- カメラ・太陽・露出はシーン既定で全素材共通。エンジン Cycles CPU、960×540、32サンプル適応+OIDNデノイズ、1枚 約110秒
- 素材は全建物メッシュへ単一 Principled を適用（porcelain / gold / chrome / ice の4種を生成。glass/crystal は次ラウンド）
- 成果物: output/blender/exp003-blender-{porcelain,gold,chrome,ice}.png（Museが全画像を直接読んで評価）

### 技術評価
- 4枚とも建物は完全描画。東京駅舎・ドーム・線路帯・丸の内高層群の形状が全素材で読める。描画不具合なし。
- chrome の左端の近景建物面にデノイズ由来の粒状感（32サンプルでは平面金属が不足）。高サンプル化で解消見込み。
- 画角端（左端・右下隅）に近景建物の断片が入る（元シーンの既知特性）。

### クリエイティブ評価（Muse判定・要ユーザー最終確認）
- **gold が第一印象最強**。街全体が金に変わる意外性、ドームの造形が際立ち、暖色の反射で「実在の東京駅」と「非現実の素材」の落差が最大。
- **porcelain が形状の読みやすさ最良**。白磁のジオラマ感が清潔で、駅舎シルエットが最も明瞭。比較の基準点として優秀。
- **chrome は迫力があるが情報量過多**。反射で高層群の輪郭が溶け気味。線路帯の金属の流れは美しい。
- **ice が最も弱い**。不透明な淡青では磁器との差が小さく「氷」に読めない。透過（transmission）なしでは成立しないという学び。

### ACT（改善仮説→次実験）
- H1: gold × 夕景寄りの太陽（低角度・暖色）+ 露出微減でドラマを増す（Blender EXP-003b）。
- H2: ice は transmission 0.6 + 厚み設定で再挑戦。それでも読めなければ素材として撤退。
- H3: chrome は 128 サンプルで粒状感の解消を確認してから最終判定。
- Navara版 Controlled との関係: Blenderで「素材の当たり外れの当たり」を先に付け、Navaraでは勝ち素材の再現度を検証する順序が効率的（レンダリング経路の分担）。

## PDCA #3 — Blender改善仮説ラウンド（2026-11-05、Muse評価済み）
PDCA #2 の仮説 H1〜H3 を同一カメラで検証した。成果物: output/blender/exp003b-*.png（Museが全画像を直接読んで評価）。

- **H1（gold×低太陽+露出-0.25）: 支持**。金が濃くなり、駅舎とドーム基部に強いハイライトが走って「夕景の宝物」感が増した。第1ラウンドの gold よりドラマがある。一方で左端の近景建物が大きな暗い金の面として主張する（画角端問題が増幅）。
- **H2（ice×透過0.65）: 不支持**。全体が乳白の霧のようになり、遠景が溶けて形状の可読性がむしろ低下した。全建物一様の透過は LOD2 の中実ジオメトリでは「氷」に読めない。**判定: 一様 ice は撤退**。ただし「氷がダメ」なのではなく「一様適用がダメ」という学び。
- **H3（chrome×128サンプル）: 支持**。第1ラウンドで見えた平面金属のデノイズ粒がほぼ解消し、反射が滑らかになった。chrome は高サンプル前提で採用可能。

### 新仮説（PDCA #3 の ACT）
- **H4「ヒーロー素材」**: 都市全体は porcelain（可読性最良）にし、ランドマーク（東京駅舎）だけを gold にする。素材の意外性と実在感の両立を狙う。一様適用の限界（ice の失敗と gold の全面感）からの帰結。
- **H5 画角端の処理**: 左端・右下隅の近景断片は、カメラをわずかに引く/寄せるか、ポストで 5% クロップして断片を除く方が作品化に効く。次ラウンドで A/B する。
