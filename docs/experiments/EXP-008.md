  URL: https://gic-plateau.s3.ap-northeast-1.amazonaws.com/2025/takeshiba/13999_tokyo_udx-mlit_2023_citygml_2_sample-takeshiba_op.zip

## 変換（2026-11-06）
- 版は LOD サブバージョンの組（203040 / 213141 / 223242 / 223342）。最高版 223342 の4タイルを変換。
- 変換器に --target-crs を追加（東京は EPSG:6677、アンカー 35.6550, 139.7620）。テスト合格。
- 結果: 4,127棟（LOD1 530 / LOD2 3,574 / LOD3 22 / **LOD4 1**）、205万頂点、OBJ 115MB。
- **東京ポートシティ竹芝 = bldg_4ab21821-b73b-4ef2-95b4-de2859999fc7**（唯一のLOD4）:
  946,621頂点（全体の46%）、footprint 104×155m、高さ209.1m（実物のオフィスタワー 208.7m と一致）、
  中心 local (-94, 7)。

## 検証（2026-11-06、EXP-007の型で）
- GSI航空写真ベースマップ（z18、アンカー投影点 -6458.93, -38273.58、範囲 x[-1250,1350] y[-700,1550]）を作成し真上重ね合わせ: 浜離宮・竹芝ふ頭・汐留の高層群が写真と一致し、金のポートシティもふ頭側の正しい区画に乗る — 配置検証OK（exp008-verify-nadir.png）。
- 斜め（東京湾側）: 金のタワーが立つが、LOD4 の外壁が薄いシェルのため金属ゴールドだと半透明の琥珀色に見え、内部の床スラブが透ける。欠陥でもあり個性でもある — ヒーローでは「ソリッドな金」vs「X線タワー」の2案を比較する。
- pale-faded ベースマップは斜め視点では水面まで白く抜ける。ヒーローでは通常の pale 版を使う。

## ヒーロー素材比較（2026-11-06）— 「2案」は不成立だった
- ソリッド金（metallic 0.9 / roughness 0.42 / lift 0.06）と X線（1.0 / 0.30 / 0.22）を遠・近 4 構図で比較 → **どの構図でも差がほぼ出ない**。透け感の正体は素材ではなく、薄いシェル越しに見える内部構造と発光リフトの相互作用で、屋外の通常角度ではファサード自体が不透明に描かれるため。素材ノブでの差別化は打ち切り、ソリッド設定に一本化。
- 構図の勝ちは V 案: 湾側やや高く (500,-450,150) → target (-94,7,80)、40mm。タワー全高＋基壇のテラス（BIM の段状低層部）が白い前景の間に覗く。低角度の太陽（62,8,128°）＋露出 -0.25 で金の深みが増す（東京駅 PDCA と同じ傾向）。
