# EXP-009 — 共通基盤: 空の余白をなくす（カメラ専用 物理スカイ）

## PLAN
- 仮説: 全ヒーロー共通の弱点「上部が平らなグレーの余白」は、世界背景を単色から物理スカイ（Nishita）に変えれば解消できる。ただし世界はIBL（照明）も兼ねるため、単純な差し替えは露出を壊す危険がある。
- 成功条件: 素材のコントラスト（磁器の陰影・金の深み）を保ったまま、上部に空としてのグラデーションが入ること。竹芝ヒーロー構図で同一条件A/B比較。

## DO
1. 素朴な差し替え（スカイを照明にも使う、強さ0.7）→ **失敗**。全体が白飛びし、金は金属反射が空に引っ張られてクリーム色に抜けた。
2. Light Path（Is Camera Ray）で分離: 照明は従来の単色ワールドのまま、カメラにだけスカイを見せる → 成功。素材コントラストを保持したまま地平線の暖かい霞＋上部の淡い青灰のグラデーションが入った。

## CHECK
- 技術: 再現可（build_takeshiba_scene.py の `--sky nishita --sky-elev 25 --sky-rot 128`）。追加コストなし。
- クリエイティブ: 改善は実在するが控えめ。高度25°のNishitaは地平線がほぼ白く、上部の色も淡い。「劇的な夕景」ではなく「余白が空になった」レベル。より低い高度（12°前後）にすると暖色が強まるが、シーン照明との色温度の不整合リスクがある。

## ACT
- 採用（基盤として）: カメラ専用スカイの方式を標準化する。東京駅（render_hero.py）・万博（build_expo_scene.py）への展開は各シーンの再レンダ時に。
- 竹芝ヒーローのスカイ版を最終画質で描画済み（exp008-hero-portcity-gold-sky.png）。素材・構図は無変更で、上部が均一グレーから地平線の霞＋淡いグラデーションに変わった。改善は控えめ — どちらを候補とするかはユーザーの目視判断。
- 教訓: Blenderのワールド差し替えは「背景」ではなく「照明の変更」。見た目だけ変えたい場合は Light Path 分離が正路 — 他シーンでも使い回せる型。
