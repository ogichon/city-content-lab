# EXP-002 CITY GROWTH — 地図から都市が生える

## PLAN
- 仮説: 実在の建物が順序を持って出現すると、静止画にはない「街ができあがる」物語性が生まれる。順序の設計（中心→外側 / 低→高 / ランダム / 巨大ビル最後）で印象が大きく変わるはず。
- 実現方法: FeatureEvaluator の `show` を、アニメーション進行度と建物ごとの閾値（重心距離・高さ・seededRank）で制御。12秒固定で4案を公平に比較。
- 明示: 実際の都市建設の歴史再現ではない（UIにも表示）。
- 成功条件（技術）: 4案が再生・リセットでき、遅れて届くタイルにも現在状態が適用される。bfcache復帰で凍結しない。
