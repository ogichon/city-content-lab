# EXP-019 — ステージが始まらない問題: idle ゲートの撤廃

## 証跡（プローブ v3 の自己診断、ユーザー提供 image-67）
`probe 8s f57 · init` — 秒数もフレームカウンタも進んでいるのにサンプラが
一度も走っていない。サンプラの条件は「公演開始後」であり、つまり公演が
開始していない。開始条件はエンジンの idle（タイル読み込み完了）待ちで、
LOD2 の重いタイルセットでは streaming が続いて idle が来ない／非常に遅い。
ユーザーが見てきた「変化なし」の主因はこれで、舞台は静止画のままだった。

## DO
- ウォッチドッグ追加: セットアップ完了から3秒経過しても idle が来なければ
  公演を開始する（タイルは公演中も逐次精細化される）。idle が先に来れば従来どおり即開始。
- プローブのサンプリング条件から「公演開始後」を外し、開始前でも輝度を測る。
- ハートビートに wait / run の状態表示を追加。

## CHECK
次回スクショで `run` 表示と輝度数値が出れば確定。あわせて、公演が実際に
カメラワークとして動くことをユーザーの目視で確認する。
